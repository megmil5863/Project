# Megan Miller - Portfolio

## Overview

This project is a personal portfolio website created by Megan Miller to showcase my web development skills, projects, and coursework.

The portfolio demonstrates the use of HTML, CSS, and JavaScript to create an interactive and responsive website. The page includes an About Me section, skills list, featured content, dynamically generated projects, a contact form, a welcome modal, and a Dark Mode feature.

## Features

- Personal About Me section
- Dynamically generated skills list
- Featured university and personal project content
- Three custom JavaScript project objects
- Project array containing the project objects
- Projects dynamically displayed using JavaScript DOM manipulation
- Project information stored in `sessionStorage`
- `JSON.stringify()` used to convert project data into a string
- `JSON.parse()` used to retrieve project data from `sessionStorage`
- Project titles, summaries, images, and GitHub repository links displayed dynamically
- Welcome modal with Close button
- Dark Mode toggle
- Dark Mode preference saved using `localStorage`
- Contact form with submission confirmation
- Responsive mobile layout
- CSS tooltip for the contact form button

## Technologies Used

### HTML

HTML is used to create the structure and content of the portfolio website.

### CSS

CSS is used to control the appearance, layout, colors, spacing, responsive design, Dark Mode styling, modal, project cards, and form elements.

### JavaScript

JavaScript is used to add interactive functionality and dynamically modify the webpage.

JavaScript features used in this project include:

- Arrays
- Objects
- `forEach()` loops
- DOM selectors
- DOM element creation
- Event listeners
- Conditional statements
- `JSON.stringify()`
- `JSON.parse()`
- `sessionStorage`
- `localStorage`
- Timers using `setTimeout()`
